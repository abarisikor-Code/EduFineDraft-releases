# EduFineDraft — 공개 배포를 마칩니다

EduFineDraft(에듀파인 기안 초안 도우미)의 공개 배포를 마쳤습니다. 그동안 써 주셔서 감사합니다.

- 여기에는 마지막 안내판(v1.9.0)만 있습니다. **이 업데이트를 설치하면 프로그램 기능이 멈춥니다.**
- 이미 만든 초안과 저장 파일은 프로그램 안 [최근 초안]과 [결과 폴더]에서 그대로 열어 볼 수 있습니다.
- 프로그램을 지우려면 Windows 설정 › 앱에서 EduFineDraft 를 제거하세요.

`latest.json` 은 예전 버전이 업데이트를 확인할 때 읽는 파일입니다.
